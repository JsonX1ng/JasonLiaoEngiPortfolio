### What I did:
- Wrote PLC Add on Instrucitons (AOIs) in Studio 5000 to prevent a pair of quadrant Shiploaders from colliding with each other and a spout changeout tower using GNSS coordinates.
- Created Automation Design Documents (ADDs) and performed Factory Acceptance Tests (FATs) for multiple PLC programs and their respective HMIs
- Debugged and wrote software factory acceptance tests and videos for a Stacker-Reclaimer's HMI in FactoryTalk View Studio
- Used Grafana, Influx DB, and NodeRED to historize PLC tags for an existing Shiploader
- Helped gather information for migrating an outdated Kocks (Kone) Crane HMI to Ignition

### What I learned:
- How to conduct factory acceptance tests for PLC programs
- How to write maintainable and robust PLC routines such as input/output buffers, fault/warning generation, and the sequence of permissions, requests, and commands to comply with client standards
- How the many electromechanical parts of a bulk material handling system work together such as VFDs, Motor Contactors, rail clamps, E stops, various analog and digital sensors, etc.
- How to link and create tags from a PLC through an HMI server to animate and interface with HMIs
- How to create intuitive, robust, and interactive HMI screens and link information through an HMI server.
- How to read and interpret technical documentation and parse through existing code for brownfield projects.

### Tools Used:
- Studio 5000 Logix Designer (Ladder logic, structured text, I/O tree configuration)
- Studio 5000 Logix Emulate
- FactoryTalk View Studio (HMI screen creation and server setup)
- SIMATIC Manager
